Deployment Guide

部署指南

本指南将帮助你将石野™ ISHINO 作品集网站部署到互联网上，让全世界都能访问。以下提供 4 种方案，从最简单到最专业依次排列。

项目结构

部署前请确认项目文件结构如下：

pes/ ├── index.html # 首页 ├── works.html # 精选作品页 ├── more-works.html # 画廊页 ├── contact.html # 联系页 ├── project.html # 项目详情页 ├── css/ │ └── style.css # 样式文件 └── js/ └── main.js # 脚本文件

注意：这是一个纯静态网站（HTML + CSS + JS），无需数据库或后端服务。图片通过 Unsplash CDN 加载，确保网络通畅即可。

方案一：Vercel

推荐 · 最简单

Vercel 部署（免费 · 5分钟）

Vercel 是最简单的静态网站部署平台，支持自动 HTTPS、全球 CDN，且完全免费。

费用：免费 技术要求：无 全球访问：支持

步骤

  1. 注册 vercel.com 账号（可用 GitHub 登录）
  2. 将 pes 文件夹上传到 GitHub 仓库（或直接拖拽）
  3. 在 Vercel Dashboard 点击 "Add New Project"
  4. 选择你的仓库或直接拖拽文件夹到部署区域
  5. 点击 "Deploy"，等待 1-2 分钟
  6. 部署完成后，获得 https://你的项目名.vercel.app 地址

快速方式：打开终端，在 pes 文件夹中运行以下命令：

npx vercel # 按提示操作，选择默认设置即可 # 完成后会得到一个可访问的 URL

方案二：Netlify

拖拽部署

Netlify 部署（免费 · 3分钟）

Netlify 支持直接拖拽文件夹部署，无需任何命令行操作。

费用：免费 技术要求：无 自动 HTTPS：支持

步骤

  1. 注册 netlify.com 账号
  2. 进入 Dashboard，找到 "Sites" 页面
  3. 将 pes 文件夹直接拖拽到虚线框区域
  4. 等待上传完成（约 10-30 秒）
  5. 获得 https://随机名称.netlify.app 地址
  6. 可在 Site Settings 中修改子域名

方案三：GitHub Pages

开发者友好

GitHub Pages 部署（免费 · 10分钟）

适合已有 GitHub 账号的用户，可与代码仓库管理结合。

费用：免费 需要：GitHub 账号 自定义域名：支持

步骤

  1. 在 GitHub 创建新仓库，例如 ishino-portfolio
  2. 将 pes 文件夹内所有文件推送到仓库：
cd C:\Users\leo\Desktop\pes git init git add . git commit -m "Initial commit" git branch -M main git remote add origin https://github.com/你的用户名/ishino-portfolio.git git push -u origin main
  1. 进入仓库 Settings → Pages
  2. 在 "Source" 下选择 "Deploy from a branch"
  3. 选择 main 分支，文件夹选 / (root)
  4. 点击 Save，等待 1-2 分钟
  5. 访问 https://你的用户名.github.io/ishino-portfolio/

方案四：自有服务器

专业方案

Nginx 服务器部署（适合自有 VPS/云服务器）

如果你有自己的服务器（如阿里云、腾讯云、AWS EC2），可以使用 Nginx 部署。

费用：服务器费用 需要：SSH 访问权限 完全控制：支持

步骤

  1. 通过 SSH 连接到服务器：
ssh root@你的服务器IP
  1. 安装 Nginx：
apt update && apt install nginx -y # Ubuntu/Debian # 或 yum install nginx -y # CentOS/RHEL
  1. 创建网站目录并上传文件：
mkdir -p /var/www/ishino # 在本地使用 scp 上传文件： scp -r C:\Users\leo\Desktop\pes\* root@你的服务器IP:/var/www/ishino/
  1. 配置 Nginx：
nano /etc/nginx/conf.d/ishino.conf

粘贴以下配置：

server { listen 80; server_name your-domain.com; # 替换为你的域名或IP root /var/www/ishino; index index.html; location / { try_files $uri $uri/ =404; } # 静态资源缓存 location ~* \.(css|js|jpg|png|gif|svg|woff2)$ { expires 30d; add_header Cache-Control "public, immutable"; } # 错误页面 error_page 404 /index.html; }
  1. 测试并重启 Nginx：
nginx -t # 测试配置 systemctl restart nginx # 重启服务 systemctl enable nginx # 设置开机自启
  1. （可选）配置 HTTPS 证书：
apt install certbot python3-certbot-nginx -y certbot --nginx -d your-domain.com # 按提示操作，自动配置 SSL 证书

方案对比

Vercel / Netlify

零配置，拖拽即部署，免费，全球 CDN 加速。适合快速上线和个人作品集。

GitHub Pages

与代码仓库集成，版本管理方便，免费。适合开发者。

自有服务器

完全控制，可绑定自定义域名，支持复杂配置。适合企业级需求。

Cloudflare Pages

类似 Vercel，但使用 Cloudflare 全球网络，在国内访问速度更优。免费。

自定义域名

如果你有自己的域名，可以在任意平台上绑定：

  • Vercel：Dashboard → Settings → Domains → 添加域名
  • Netlify：Site Settings → Domain settings → 添加自定义域名
  • GitHub Pages：仓库 Settings → Pages → Custom domain
  • 自有服务器：在域名 DNS 中添加 A 记录指向服务器 IP

DNS 配置示例：添加 A 记录，主机记录填 @（或 www），记录值填你的服务器 IP 或平台提供的地址。DNS 生效通常需要 10分钟-24小时。

常见问题

图片不显示？

网站使用 Unsplash CDN 图片，确保服务器能访问外网。如需离线使用，可将图片下载到本地 assets/ 文件夹并修改 HTML 中的图片路径。

字体不加载？

Google Fonts 需要网络访问。如在国内部署且访问较慢，可在 CSS 中将 @import 替换为国内 CDN 镜像，或将字体文件下载到本地。

部署后页面空白？

检查文件路径是否正确。确保 css/style.css 和 js/main.js 路径在 HTML 中使用相对路径（css/style.css 而非 /css/style.css）。
